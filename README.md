# Qxiiphoto 姿势包

给 Minecraft Java 版玩家模型加一套**可自由调整的骨骼**：头 / 身体 / 左右手 / 左右腿，每根骨头都能平移 + 旋转。
皮肤第二层（帽子、夹克、袖子、裤腿）、四件盔甲、主副手持物品**全部自动跟随**。

* **一个 mod 搞定，全在游戏内**：`qxii-posemod-3.11.0.jar` —— 不需要资源包，不需要 EMF / ETF，**也不需要浏览器**
* **按 X 打开游戏内编辑器**（可在「选项 → 控制」改键，或输入 `/qxp`）：
  左侧实时预览 + 右侧控制面板，拖滑块即时生效
* **改完立刻生效** —— 不用按 F3+T、不用重载、不用切窗口
* **关闭模型＝暂时停用**：数值全部保留，点「启用模型」立刻恢复（不再清零）
* **临时缓存**：把当前姿势存成多份缓存，点一下就能换回来（游戏内和网页端共享同一份）

---

## 一、安装

1. 前置：**Fabric Loader** + **Fabric API**（1.21.11 版本即可；不需要 EMF、ETF，也不需要任何资源包）
2. 把 **`mod/build/libs/qxii-posemod-3.11.0.jar`** 放进 `.minecraft/mods/`
3. 启动游戏，按 **X**（默认键，可在「选项 → 控制」里改，分类叫「Qxiiphoto 姿势包」）

---

### 在全新电脑上部署（给别人用时的清单）

| 必须项 | 版本要求 | 说明 |
|---|---|---|
| Minecraft Java 版 | **1.21.11**（精确匹配） | Fabric mod 与游戏版本强绑定；换版本要重新编译（见第七节） |
| Fabric Loader | **≥ 0.19.0**（推荐 0.19.3） | 安装时选 1.21.11 |
| **Fabric API** | 1.21.11 版（如 `0.141.6+1.21.11`） | **必需** —— 按键、命令、客户端 tick、视口注册都用它；缺失时游戏启动阶段就会明确报错 |
| 本 mod | `qxii-posemod-3.11.0.jar` | 放进 `.minecraft/mods/` |
| Java | **21+** | **玩游戏不用自己装**（启动器自带 JRE）；只有自己编译才需要 JDK 21 |

**完全不需要**：资源包、EMF/ETF、Python 或本地服务器、手改配置（自动生成 `config/qxp_pose.json`）、联网（除本机 127.0.0.1 外不访问网络）。

**部署 5 步**：装 MC 1.21.11 → 装 Fabric Loader → 下载 Fabric API → 把 Fabric API 与本 mod 一起放进 `mods/` → 启动后按 **X**（键位可在「选项 → 控制」改）。

**验证**：`/qxp status` 会打印版本与运行状态（含 `3D视口=开/关`）；异常看 `logs/latest.log` 里的 `qxp-pose`。

**容易踩的坑**

1. **版本必须精确匹配 1.21.11**：mixin 目标与 GUI 渲染 API 都随版本变化。给别的版本用要改 `gradle.properties` 重新编译，且可能需同步调整 mixin 目标（见第七节）。
2. **不要同时开其它「玩家模型」资源包**（FA+Player / Polaris 动作优化 / DetailedAnimations / JustExpressions 等）：它们和本 mod 会**叠加**渲染。本 mod 的渲染不走资源包，正确做法是**关掉那些资源包**。
3. **端口**：mod 会在本机 `8731~8745` 里挑一个空闲端口提供网页版编辑器。全部被占用时游戏内 GUI 仍可正常用，只有 `/qxp web` 会失败。
4. **多人游戏**：这是客户端 mod，只改你自己的画面，别人看到的是原版模型。
5. **首次打开编辑器**显示的是内置皮肤（Alex 细臂 + 内置皮肤），使用者无需自己导入。

## 二、使用

| 操作 | 说明 |
|---|---|
| 按 **X** | 打开**游戏内编辑器**（会自动切到第三人称，方便边调边看） |
| `/qxp` | 同上，不想用键位就用命令 |
| `/qxp off` | **关闭模型**＝暂时用回原版模型，**数值全部保留**（不是清零） |
| `/qxp on` | 重新启用模型，恢复关闭前的那份姿势 |
| `/qxp zero` | 真正把数值全部归零（模型开关状态不变） |
| `/qxp all` | 切换作用范围：默认**只影响自己**；打开后所有玩家都用这个姿势 |
| `/qxp status` | 查看当前状态、模型开关、缓存数量、兼容补丁开关与触发计数 |
| `/qxp compat` | 查看/切换兼容补丁：`/qxp compat <backpack / strawhat / elytra / cape>`（Tab 可补全） |
| `/qxp web` | （可选）在浏览器里打开功能更全的网页版编辑器；游戏内编辑器右下角也有「打开web端」按钮 |

### 游戏内编辑器

```
┌──────────────────────────────────────┬────────────────────┐
│                                      │     姿势编辑器      │
│                                      │ [▶头部][身体][左手] │
│          实时 3D 预览                 │ [右手][左腿][右腿]  │
│      （就是你的皮肤/盔甲/手持物）      │ [平移 W][旋转 E]    │
│                                      │ 俯仰 X  ──●──  12°  │
│      同时，世界里的角色                │ 偏航 Y  ──●──   0°  │
│      也在同步变化                      │ 翻滚 Z  ──●──  -5°  │
│                                      │ [重置本部件][全部归零]│
│                                      │ [撤销]  [关闭模型]   │
│                                      │ 临时缓存 2/12        │
│                                      │ [待机姿势][覆盖][×]  │
│                                      │ [战斗姿势][覆盖][×]  │
│                                      │ [＋ 存为缓存]        │
│                                      │ [  完成  ][打开web端]│
└──────────────────────────────────────┴────────────────────┘
```

* **点部件按钮**选中要调的骨头（选中的会带 `▶`），拖六个滑块也能精确调整
* **直接拖左侧预览就能摆姿势**（BlockBench 那种手感）：
  * 水平拖 ＝该模式的第一个轴，垂直拖 ＝第二个轴，**按住 <kbd>Shift</kbd> 拖 ＝第三个轴**
  * <kbd>W</kbd> 切「拖拽＝平移」，<kbd>E</kbd> 切「拖拽＝旋转」（面板底部会显示当前模式与实时读数）
  * **预览区滚轮**＝微调当前轴；按住 <kbd>Ctrl</kbd> 拖动/滚动＝吸附（平移 1 像素 / 旋转 15°）
  * <kbd>R</kbd> 重置当前部件；每次拖拽算一步，可以 <kbd>Ctrl+Z</kbd> 撤销
* **关闭模型**＝**暂时停用**：立刻用回原版模型，**数值一个都不丢**；按钮随即变成**启用模型**，点一下就恢复
  （想真正清零用「全部归零」或 `/qxp zero`）
* **临时缓存**：点「＋ 存为缓存」把当前姿势存一份（最多 12 份）；点缓存名＝**应用并启用**，
  **⟳**＝用当前姿势覆盖它（改某个缓存＝点它应用 → 调滑块 → 点 ⟳），**×**＝删除；缓存多于一屏时在列表上**滚轮翻页**。
  缓存写在 `config/qxp_pose.json`，**网页端看到的是同一份**，两边都能增删改
* **重置本部件 / 全部归零 / 撤销** 都在面板上；**完成**关闭界面（姿势自动保存）
* 右下角 **打开web端** 直接拉起浏览器里的网页版编辑器（和游戏内共用同一份数值）
* 打开界面时**世界不会暂停**，而且不会压暗背景 —— 可以对照世界里的真实效果（光照、盔甲、手持物）
* 姿势保存在 `config/qxp_pose.json`，重启游戏依然在

### 数值方向（与原版完全一致）

`+X` 往玩家左侧 · `+Y` **向下** · `+Z` 往身后；旋转的正负与原版 `xRot/yRot/zRot` 相同。

### 网页版编辑器（可选，`/qxp web`）

界面为 **Spline 风格**（按 spline.design 的规范重做）：纯黑"虚空"底、悬浮玻璃面板与顶栏、
只用 12/24/胶囊三档圆角、不加描边和投影（层次靠半透明白叠加），字重不超过 500，
饱和色只留给主按钮的 Spline 蓝 `#0062ff`，视口里只有一层蓝紫柔光。

功能更全：在视口里直接拖 **红/绿/蓝箭头、平面块、旋转圆环**（BlockBench / Unreal 那套手柄操作）、
撤销重做、左右镜像、贴图预览、导入皮肤等。两种编辑器的数值完全通用。

**模型开关与临时缓存（3.10.0 新增）**

| 功能 | 说明 |
|---|---|
| **关闭模型 / 启用模型** | 关闭＝游戏里立刻用回原版模型，**编辑器里的数值全部保留**；顶栏按钮随即变成「启用模型」，点一下恢复。（纯资源包路线没有"开关"这一说，关闭时会往包里写一份全 0，数值仍留在编辑器里） |
| **临时缓存** | 「存为缓存」存一份，名称可自己填（留空自动命名）；点名字＝**载入并启用**、**⟳**＝用当前姿势覆盖、**× 点两次**＝删除（第一次变红提示，3 秒内再点确认，点名字取消）。<br>**连上游戏时这份列表就是游戏内那份**（两边同步增删改，存在 `config/qxp_pose.json`）；没连游戏时存本机（沿用旧的"预设"数据） |

**文本互操作（3.9.0 新增）**

| 功能 | 说明 |
|---|---|
| **粘贴姿势** | 把姿势文本直接贴进来就用。支持四种写法，也可以**整段粘贴 `.jpm` 文件内容**：<br>`var.qxp_head_rx = torad(30)`　`"var.qxp_head_rx": "torad(30)"`　`head.rx = 30`　`body.ty = -2` |
| **复制姿势表达式** | 输出的是**可回贴**格式（`bone.axis=value`），复制出来能直接粘回去 |
| **双向同步** | 装了 mod 时：网页改完立刻进游戏；**游戏内按 X 改完，网页 1.5 秒内自动跟随**（同步只读游戏、不覆盖你正在编辑的内容） |

所以想让两个编辑器之间搬姿势，直接复制粘贴即可 —— 甚至可以把别人发的姿势表达式（
比如 `.jpm` 里的几行）贴进来直接生效。

## 三、兼容性

* **渲染由 mod 直接改玩家模型的部件**（4 个客户端 mixin，只做"在原版算完之后叠加一个偏移"），
  不替换渲染器、不改实体、不改贴图管线。原版动作（走路、潜行、视角、挥手臂）全部保留。
* **盔甲与手持物自动跟随**：1.21.11 的装备渲染复用同一套模型部件，所以它们天然跟着姿势走。
* **皮肤第二层自动跟随**：帽子/夹克/袖子/裤腿本来就是这些部件的子节点。
* **第一人称不叠加**：手持物品渲染期间会跳过姿势，免得手里的东西跑偏（第三人称正常）。
* **第三方穿戴物的跟随方式（实测结论）**：

  | 物品 | 它是怎么跟随的 | 本 mod 是否需要补丁 |
  |---|---|---|
  | 原版盔甲 / 玩家模型本体 | 渲染时读玩家部件 | 不需要（核心机制） |
  | 旅行者背包 | **自己会把身体部件变换抄到它的模型上**，本来就跟随 | **不需要**（默认关闭；开了会变成 2 倍偏移） |
  | 森罗物语草帽 | 自己完全不跟随 | **需要**（默认开启，在它的渲染入口补一次头部姿势） |
  | 鞘翅 / 披风 | 装备通道自身跟随 | 不需要（补丁默认关闭，仅在确实不跟随时用 `/qxp compat` 打开） |

  四个补丁都能在游戏内单独开关，遇到对应物品表现异常时先开关对照即可定位。

* **作用范围**：默认只影响你自己（`/qxp all` 可改成所有玩家）；这是客户端 mod，别人看到的还是原版模型。
* **和其它动作类 mod**（NotEnoughAnimations、FirstPerson、Polaris 等）**一般能共存**：它们改同一批部件，
  本 mod 是在它们算完之后再叠加。若某个 mod 恰好在更后面覆盖同样的部件，那几个部件可能不跟随姿势。
* **别同时开旧的资源包方案**：如果你还在用 `QxiiphotoPose` 资源包（EMF 读取的那套），会和 mod 双重叠加，
  打开编辑器时 mod 会提醒你去「选项 → 资源包」里关掉它。

## 五、原理（一页看懂）

```
按 X
 └─ 打开游戏内界面：左边用原版背包同款的方式渲染你自己的模型（连预览都带盔甲和手持物）
     └─ 拖动滑块 → 数值写进 QxpPose（内存）+ config/qxp_pose.json
         └─ 每帧渲染玩家模型时：先 resetTransforms() 回到默认姿势，
            等原版（或别的动作 mod）算完动作后，再把你的数值叠加到 6 个部件上
```

关键点是"**只叠加、不替换动作**"：每个部件拿到的都是 `原版这一帧算出来的值 + 你调的偏移`，
所以走路、潜行、摆动全都保留，只是在你调的方向上多一个量。每帧开头会先重置，所以**不会累加**。

## 七、换成别的 MC 版本

改 `mod/gradle.properties` 里的 `minecraft_version` / `yarn_mappings` / `fabric_version`，然后 `cd mod && ./gradlew build`。

两点注意：

* **JDK**：1.21.x 用 JDK 21 编译，26.x 用 JDK 25（Gradle 跑在 JDK 25 上，编译目标由 toolchain 决定，见 `org.gradle.java.home`）
* **mixin 目标**：若新版改了 `PlayerEntityModel.setAngles` / `PlayerEntityRenderer.updateRenderState` /
  `HeldItemRenderer.renderFirstPersonItem` 的签名，需要同步调整（构建报"找不到方法"就是这里）；
  另外 GUI 相关的 `Click` / `KeyInput` / `DrawContext` 也可能随版本变化

## 八、旧的纯资源包方案（可选）

不想用 mod 的话，旧方案仍然可用，只是渲染依赖 **EMF + ETF**：

1. 装 `EMF` + `ETF`
2. 把 `QxiiphotoPose.zip` 放进 `.minecraft/resourcepacks/` 并启用（若同时有其它「玩家模型」包，放到列表最上面）
3. 浏览器打开 `editor/index.html`：点「连接游戏资源包文件夹」写入，或「导出资源包 .zip」手动放
4. 改完在游戏里按 **F3+T** 重载

这套和 mod 版**不能同时开**（会双重叠加）。两者共用同一份数值与同一个网页编辑器。
