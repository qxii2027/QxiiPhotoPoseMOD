三步装好

  1. 装好 Fabric Loader（选 1.21.11）与 Fabric API
  2. 把下载的 qxii-posemod-3.11.0.jar 放进 .minecraft/mods/
  3. 启动游戏，按 X 打开姿势编辑器（键位可在「选项 → 控制」改）

同一台电脑上，Fabric API 与本 mod 的 jar 不能重复放两份，否则会报重复模组。

游戏里能做什么

  • 六个部件 × 六个轴：拖滑块或直接拖预览里的角色
  • 关闭模型＝暂时用回原版动作，数值全部保留；点「启用模型」恢复
  • 临时缓存：把当前姿势存成多份，点一下换回来（最多 12 份）
  • 右下角「打开web端」＝浏览器里的进阶编辑器，两边数值互通

上手前先知道

  • 版本必须精确匹配 1.21.11：Fabric 模组和游戏版本强绑定，换版本要重新编译。
  • 别同时开其它「玩家模型」资源包（FA+Player / Polaris / DetailedAnimations 等），会和本 mod 叠加渲染；本 mod 不走资源包，正确做法是把它们关掉。
  • 这是客户端 mod：只改你自己的画面，别人看到的还是原版模型；多人服务器不用装任何东西。
  • 数值存在哪：config/qxp_pose.json（姿势、模型开关、临时缓存都在里面），重启游戏依然在。
  • 装完怎么确认：游戏里输入 /qxp status，会打印版本、模型开关、缓存数量与补丁状态。
